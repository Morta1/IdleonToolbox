Everything listed below is "in order" of priority

DAMAGE PRESET

TAB 1

  • Gilded Sword -> Sharpened Axe -> 50 points Idle Brawling -> Meat Shank -> Health Booster -> Fist Of Rage

  • Book Of The Wise (upgrade according to accuracy needed)

TAB 2

  • 25 points Power Strike = 25 points Whirl = 45 points Double Strike = 1 point Firmly Grasp It

  • Carry A Big Stick -> Strength In Numbers -> Health Overdrive -> 'Str'Ess Tested Garb = Absolute Unit

  • Any additional points put in Firmly Grasp It

TAB 3

  • 25 points Bear Swipe = 25 points Axe Hurl

  • (Wait until World 4 before leveling No Pain No Gain , you need enough base HP to avoid one shot) -> Str Summore -> Apocalypse Zow (only breakpoint)

  • Back To Basics -> Monster Decimator ----- -> Fistful Of Obol = Strongest Statues

STAR TALENTS - Tab 1

  • Will Of The Eldest -> Beginner Best Class (capped at 10% of highest level - ie level 100 means skill level 10)

  • Tick Tock = Attacks On Simmer = Goblet Of Hemoglobin

STAR TALENTS - Tab 2

  • Dungeonic Damage (More dungeon = more damage) -> Frothy Malk -> Telekinetic Storage

  • 1 point in both Printer Sampling and Shrine Architect

  • Optional: Just Exp , Pulsation Mega Crit

-----

SKILLING PRESET

TAB 1

  • Brute Efficiency -> Idle Skilling -> Fist Of Rage

  • Optional from here on out: Star Player

TAB 2

  • Absolute Unit -> Firmly Grasp It -> 'Str'Ess Tested Garb (low conversion rate) -> Haungry For Gold -> Tempestuous Emotions

TAB 3

  • Worming Undercover -> Bobbin' Bobbers -> All Fish Diet -> Catching Some Zzz'S -> Str Summore -> Strongest Statues

  • Fistful Of Obol or if need Tab 2 points Back To Basics

TAB 4

  • Symbols Of Beyond ~R -> Overblown Testosterone -> Skill Strengthen

  • Optional from here on out: Mostly Cooking skills

STAR TALENTS - Tab 1

  • Tick Tock = Toilet Paper Postage = Will Of The Eldest

STAR TALENTS - Tab 2

  • Supersource -> Action Frenzy -> Frothy Malk -> Telekinetic Storage

  • 1 point in both Printer Sampling and Shrine Architect
