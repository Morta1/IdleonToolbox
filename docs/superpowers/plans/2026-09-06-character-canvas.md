# Character Canvas Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A `/tools/character-canvas` page that draws an Idleon character as the game does (body, hat, weapon, cape, costume, skill effect) from the game's own sprite sheets, animated, with a shareable URL and PNG download.

**Architecture:** z-processing gains a `playerSprites` export that copies six Stencyl sprite groups out of the extracted APK into `exported/player-sprites/` plus a manifest describing every sheet. The site gains a pure resolver (`utility/paperDoll.js`) that maps loadout + time to a draw list, a `<canvas>` component that draws it, and a page that wraps the canvas in pickers. No stats anywhere.

**Tech Stack:** Node (CommonJS) + `sharp` + `node:test` in z-processing; Next.js pages router + React 19 + MUI + vitest in IdleonToolbox.

**Spec:** `docs/superpowers/specs/2026-09-06-character-canvas-design.md`

## Global Constraints

- No em dashes anywhere (UI copy, comments, docs). Use a colon.
- No `useMemo`, no `useCallback`, no IIFEs in React code. The React Compiler memoizes.
- Tooltips always hang off an `InfoIcon` (`@mui/icons-material/Info`) using the project's `components/Tooltip`, never off plain text.
- Never set `image-rendering: pixelated` (or `crisp-edges`). Scale on the canvas with `imageSmoothingEnabled = false` instead.
- `data/website-data/*.json` is generated: never hand-edit. Item art IDs come from `items.json` as-is.
- No git commits in this plan. The user commits.
- The in-app Browser pane cannot load this site. Verify with Playwright against `npm run build` + `npx serve out`.
- Test commands: z-processing `npm test` (runs `node --test core/*.test.js`); IdleonToolbox `npx vitest run <file>`.
- Path aliases in IdleonToolbox: `@components`, `@parsers`, `@utility`, `@website-data`.
- The extracted APK lives at `z-processing/resources/`: `resources.mbs` and `graphics/1x/sprite-<group>-<n>.png`. Tests that need it skip when it is absent.

## Verified sprite facts (from N.js and the 2.3.523 sheets; the plan relies on these)

| Layer | Group | Frame rule |
|---|---|---|
| body | 21 | animations `0` idle, `1` walk, `2a` spear attack, `2b` bow, `2c` wand, `2_` fists, `3`..`9` skilling, `Da`, `Za`. 94x50 frames, origin (47, 50). |
| hat | 32 | sheet `1`; sheet `4` while body plays `4`. frame = ID + 2. Frames are 30x50. |
| weapon | 25 | idle/walk sheets (`0`, `1`): frame = typeOffset + ID with typeOffset = {FISTICUFF 0, SPEAR 12, BOW 28, WAND 42} (verified against the 58-frame idle sheet: 0 blank, 1..12 fists, 13..28 spears, 29..42 bows, 43..55 wands). Attack sheets (`2a`,`2b`,`2c`,`2_`): frame = bodyFrame + block × bodyFrames where block = ID for FISTICUFF, ID - 1 otherwise (2a: 176 = 16 spears × 11; 2b: 182 = 14 × 13; 2c: 169 = 13 × 13; 2_: 221 = 13 × 17). |
| cape | 574 | animation name = cape ID, own loop, behind body. |
| costume | 684 | one sheet per ATTIRE ID, 163 frames = every body pose concatenated in MBS record order (sum 162) plus one leading pad frame. |
| effect | 8 | ~37 numeric animations. Hand-mapped per talent. |

```js
// z-processing/features/_tooling/playerSprites.js
const fs = require('fs');
const path = require('path');

// The player is a paper doll of separate Stencyl actors. Each layer is one sprite group in
// resources.mbs; the frame a given item uses is derived from the item's ID (see the spec).
const PLAYER_GROUPS = { body: 21, hat: 32, weapon: 25, cape: 574, costume: 684, effect: 8 };
const REQUIRED_BODY_ANIMS = ['0', '1', '2a', '2b', '2c', '2_'];
const ATTACK_ANIMS = ['2a', '2b', '2c', '2_'];
const WEAPON_TYPE_ORDER = ['FISTICUFF', 'SPEAR', 'BOW', 'WAND'];
const HAT_TYPES = new Set(['HELMET', 'PREMIUM_HELMET']);
const HAT_FRAME_OFFSET = 2;

const sheetMeta = (record, file) => ({
  file,
  across: record.across,
  down: record.down,
  numFrames: record.numFrames,
  frameW: Math.round(record.width / record.across),
  frameH: Math.round(record.height / record.down),
  originX: record.originX,
  originY: record.originY,
  durations: record.durations?.length ? record.durations : Array(record.numFrames).fill(100)
});

const maxIdOfType = (items, type) => Math.max(0, ...Object.values(items)
  .filter((item) => item?.Type === type && Number.isFinite(item?.ID))
  .map((item) => item.ID));

// Highest ID such that every ID from 1 up to it exists. Placeholder items carry an out-of-range
// ID (a SPEAR with ID 99 in 2.3.528) and must not stretch the sheet layout; they simply have no
// art and the resolver reports them as unsupported.
const contiguousMaxId = (items, type) => {
  const ids = new Set(Object.values(items)
    .filter((item) => item?.Type === type && Number.isFinite(item?.ID))
    .map((item) => item.ID));
  let max = 0;
  while (ids.has(max + 1)) max += 1;
  return max;
};

// Idle/walk weapon sheets lay the types out back to back: blank, fists, spears, bows, wands.
// Each type starts right after the previous type's highest contiguous ID.
const weaponTypeOffsets = (items) => {
  const offsets = {};
  let next = 0;
  for (const type of WEAPON_TYPE_ORDER) {
    offsets[type] = next;
    next += contiguousMaxId(items, type);
  }
  return offsets;
};

const buildPlayerManifest = ({ records, items, version }) => {
  const layers = {};
  const files = [];
  for (const [layer, groupId] of Object.entries(PLAYER_GROUPS)) {
    layers[layer] = {};
    for (const record of records.filter((r) => r.groupId === groupId)) {
      const file = `${layer}/${record.name}.png`;
      layers[layer][record.name] = sheetMeta(record, file);
      files.push({ src: `${record.sprite}.png`, dst: file });
    }
  }

  for (const anim of REQUIRED_BODY_ANIMS) {
    if (!layers.body[anim]) throw new Error(`player sprites: body animation ${anim} missing`);
  }

  const maxHatId = Math.max(maxIdOfType(items, 'HELMET'), maxIdOfType(items, 'PREMIUM_HELMET'));
  const hatSheet = layers.hat['1'];
  if (!hatSheet || hatSheet.numFrames < maxHatId + HAT_FRAME_OFFSET + 1) {
    throw new Error(`player sprites: hat sheet holds ${hatSheet?.numFrames ?? 0} frames, need ${maxHatId + HAT_FRAME_OFFSET + 1}`);
  }

  const offsets = weaponTypeOffsets(items);
  const idleFramesNeeded = offsets.WAND + contiguousMaxId(items, 'WAND') + 1;
  if (!layers.weapon['0'] || layers.weapon['0'].numFrames < idleFramesNeeded) {
    throw new Error(`player sprites: weapon idle sheet holds ${layers.weapon['0']?.numFrames ?? 0} frames, need ${idleFramesNeeded}`);
  }
  for (const anim of ATTACK_ANIMS) {
    const bodyFrames = layers.body[anim].numFrames;
    const sheet = layers.weapon[anim];
    if (!sheet || sheet.numFrames % bodyFrames !== 0) {
      throw new Error(`player sprites: weapon sheet ${anim} has ${sheet?.numFrames ?? 0} frames, not a multiple of the body's ${bodyFrames}`);
    }
  }

  const bodyAnimOrder = records.filter((r) => r.groupId === PLAYER_GROUPS.body).map((r) => r.name);
  const poseFrames = bodyAnimOrder.reduce((sum, anim) => sum + layers.body[anim].numFrames, 0);
  const costumeSheets = Object.values(layers.costume);
  const costumePoseOffset = costumeSheets.length ? costumeSheets[0].numFrames - poseFrames : 0;
  if (costumePoseOffset < 0 || costumePoseOffset > 1) {
    throw new Error(`player sprites: costume sheet has ${costumeSheets[0].numFrames} frames for ${poseFrames} body poses`);
  }

  const manifest = {
    version,
    frameW: layers.body['0'].frameW,
    frameH: layers.body['0'].frameH,
    hatFrameOffset: HAT_FRAME_OFFSET,
    costumePoseOffset,
    weaponTypeOffsets: offsets,
    bodyAnimOrder,
    layers
  };
  return { manifest, files };
};

module.exports = { PLAYER_GROUPS, buildPlayerManifest };
```

- [ ] **Step 3: Implement the fs half**

```js
// Copies the sheets straight through: no slicing, the site reads frames by grid position.
// A missing png (a group renamed by a game update) drops that sheet from the manifest and warns,
// so one odd sheet cannot take the whole export down. The invariants in buildPlayerManifest
// still run first, so a missing body or weapon sheet still throws.
const generatePlayerSprites = async ({ records, items, version, graphicsDir, outDir }) => {
  const { manifest, files } = buildPlayerManifest({ records, items, version });
  await fs.promises.rm(outDir, { recursive: true, force: true });
  for (const { src, dst } of files) {
    const from = path.join(graphicsDir, src);
    const to = path.join(outDir, dst);
    if (!fs.existsSync(from)) {
      console.warn(`player sprites: ${src} not found, dropping ${dst}`);
      const [layer, name] = dst.replace(/\.png$/, '').split('/');
      delete manifest.layers[layer][name];
      continue;
    }
    await fs.promises.mkdir(path.dirname(to), { recursive: true });
    await fs.promises.copyFile(from, to);
  }
  console.log(`player sprites: ${files.length} sheets -> ${outDir}`);
  return manifest;
};

module.exports = { PLAYER_GROUPS, buildPlayerManifest, generatePlayerSprites };
```

```js
// IdleonToolbox/utility/paperDoll.js
// Pure paper-doll math. The game draws a player as separate actors sharing one anchor (the body
// origin, at the feet). Every rule here mirrors the game's frame selection; see the spec's
// "Verified sprite facts" table. No DOM, no React: PaperDollCanvas.jsx does the drawing.

export const CANVAS = { width: 220, height: 160, anchorX: 110, anchorY: 130 };
// Hat sheets are 30 wide against a 94 wide body frame; the game attaches the hat image at the
// actor's own (0, 0). Centered horizontally is the starting guess, tuned once by eye.
export const HAT_OFFSET = { x: 32, y: 0 };
export const DRAWN_WEAPON_POSES = new Set(['0', '1', '2a', '2b', '2c', '2_']);
const ATTACK_POSES = new Set(['2a', '2b', '2c', '2_']);
const ATTACK_BY_TYPE = { SPEAR: '2a', BOW: '2b', WAND: '2c', FISTICUFF: '2_' };
const ATTACK_BY_CLASS = { Warrior: '2a', Archer: '2b', Mage: '2c' };

export const attackPoseForType = (weaponType, baseClass) =>
  ATTACK_BY_TYPE[weaponType] ?? ATTACK_BY_CLASS[baseClass] ?? '2_';

export const frameAt = (durations, elapsedMs, loop = true) => {
  const total = durations.reduce((sum, d) => sum + d, 0);
  if (total <= 0) return 0;
  let t = elapsedMs;
  if (loop) t = ((t % total) + total) % total;
  else if (t >= total) return null;
  for (let i = 0; i < durations.length; i++) {
    if (t < durations[i]) return i;
    t -= durations[i];
  }
  return durations.length - 1;
};

const drawOp = (sheet, frame, dx, dy) => ({
  file: sheet.file,
  sx: (frame % sheet.across) * sheet.frameW,
  sy: Math.floor(frame / sheet.across) * sheet.frameH,
  w: sheet.frameW,
  h: sheet.frameH,
  dx,
  dy
});

const anchored = (sheet) => ({ dx: -sheet.originX, dy: -sheet.originY });

const poseBase = (manifest, pose) => {
  let base = 0;
  for (const anim of manifest.bodyAnimOrder) {
    if (anim === pose) return base;
    base += manifest.layers.body[anim]?.numFrames ?? 0;
  }
  return null;
};

export const resolveLayers = (manifest, state, tick) => {
  const layers = [];
  const unsupported = [];
  const bodySheets = manifest.layers.body;
  const pose = bodySheets[state.pose] ? state.pose : '0';
  const body = bodySheets[pose];
  const bodyFrame = frameAt(body.durations, tick) ?? 0;
  const bodyAnchor = anchored(body);

  if (state.cape) {
    const sheet = manifest.layers.cape[String(state.cape.ID)];
    if (sheet) layers.push(drawOp(sheet, frameAt(sheet.durations, tick) ?? 0, -sheet.originX, -sheet.originY));
    else unsupported.push(state.cape.rawName);
  }

  layers.push(drawOp(body, bodyFrame, bodyAnchor.dx, bodyAnchor.dy));

  if (state.costume) {
    const sheet = manifest.layers.costume[String(state.costume.ID)];
    const base = poseBase(manifest, pose);
    const frame = base == null ? null : manifest.costumePoseOffset + base + bodyFrame;
    if (sheet && frame != null && frame < sheet.numFrames) layers.push(drawOp(sheet, frame, bodyAnchor.dx, bodyAnchor.dy));
    else unsupported.push(state.costume.rawName);
  }

  if (state.weapon && DRAWN_WEAPON_POSES.has(pose)) {
    const sheet = manifest.layers.weapon[pose];
    const { ID, Type } = state.weapon;
    let frame = null;
    if (sheet && ATTACK_POSES.has(pose)) {
      const block = Type === 'FISTICUFF' ? ID : ID - 1;
      frame = bodyFrame + block * body.numFrames;
    } else if (sheet) {
      const offset = manifest.weaponTypeOffsets[Type];
      frame = offset == null ? null : offset + ID;
    }
    if (frame != null && frame >= 0 && frame < sheet.numFrames) layers.push(drawOp(sheet, frame, bodyAnchor.dx, bodyAnchor.dy));
    else unsupported.push(state.weapon.rawName);
  }

  if (state.hat) {
    const sheet = manifest.layers.hat[pose === '4' && manifest.layers.hat['4'] ? '4' : '1'];
    const frame = state.hat.ID + manifest.hatFrameOffset;
    if (sheet && frame < sheet.numFrames) layers.push(drawOp(sheet, frame, bodyAnchor.dx + HAT_OFFSET.x, bodyAnchor.dy + HAT_OFFSET.y));
    else unsupported.push(state.hat.rawName);
  }

  if (state.effect) {
    const sheet = manifest.layers.effect[state.effect.anim];
    const frame = sheet ? frameAt(sheet.durations, tick - state.effect.startedAt, false) : null;
    if (frame != null) layers.push(drawOp(sheet, frame, state.effect.dx, state.effect.dy));
  }

  return { layers, unsupported };
};
```

  hat: new Set(['HELMET', 'PREMIUM_HELMET']),
  weapon: new Set(['FISTICUFF', 'SPEAR', 'BOW', 'WAND']),
  cape: new Set(['CAPE']),
  costume: new Set(['ATTIRE'])
};
const SLOTS = Object.keys(SLOT_TYPES);
const POSE = /^([0-9]|2[abc_]|Da|Za)$/;

const first = (value) => (Array.isArray(value) ? value[0] : value);

export const encodeLoadout = (loadout) => {
  const query = { class: loadout.className };
  for (const slot of SLOTS) {
    if (loadout[slot]?.rawName) query[slot] = loadout[slot].rawName;
  }
  if (loadout.pose && loadout.pose !== '0') query.pose = loadout.pose;
  return query;
};

export const decodeLoadout = (query, items, classNames) => {
  const className = first(query?.class);
  const pose = first(query?.pose);
  const loadout = {
    className: classNames.includes(className) ? className : 'Beginner',
    pose: POSE.test(pose ?? '') ? pose : '0'
  };
  for (const slot of SLOTS) {
    const item = items?.[first(query?.[slot])];
    loadout[slot] = item && SLOT_TYPES[slot].has(item.Type) ? item : null;
  }
  return loadout;
};

```jsx
// IdleonToolbox/components/tools/character-canvas/PaperDollCanvas.jsx
import React, { useEffect, useRef } from 'react';
import { Box } from '@mui/material';
import { prefix } from '@utility/helpers';
import { CANVAS, resolveLayers } from '@utility/paperDoll';

// Draws the paper doll on a <canvas> at an integer scale. The animation clock and the latest
// props live in refs so the rAF loop never re-renders React: state changes are picked up on the
// next frame. Sheets are loaded once per file and cached for the component's lifetime.
const loadImage = (src) => new Promise((resolve) => {
  const img = new Image();
  img.onload = () => resolve(img);
  img.onerror = () => resolve(null);
  img.src = src;
});

const PaperDollCanvas = ({ manifest, state, playing = true, scale = 3, onEffectEnd, onUnsupported, canvasRef }) => {
  const localRef = useRef(null);
  const ref = canvasRef ?? localRef;
  const images = useRef(new Map());
  const latest = useRef({ state, playing, onEffectEnd, onUnsupported });
  latest.current = { state, playing, onEffectEnd, onUnsupported };
  const clock = useRef({ start: 0, pausedAt: null });
  const lastUnsupported = useRef('');

  useEffect(() => {
    const files = new Set();
    for (const layer of Object.values(manifest.layers)) {
      for (const sheet of Object.values(layer)) files.add(sheet.file);
    }
    let cancelled = false;
    (async () => {
      for (const file of files) {
        if (images.current.has(file)) continue;
        const img = await loadImage(`${prefix}player-sprites/${file}`);
        if (cancelled) return;
        if (img) images.current.set(file, img);
        else console.warn(`player sprites: could not load ${file}`);
      }
    })();
    return () => { cancelled = true; };
  }, [manifest]);

  useEffect(() => {
    const canvas = ref.current;
    if (!canvas) return undefined;
    const ctx = canvas.getContext('2d');
    let frame = 0;
    clock.current.start = performance.now();

    const draw = (now) => {
      const { state: s, playing: p, onEffectEnd: end, onUnsupported: report } = latest.current;
      if (!p && clock.current.pausedAt == null) clock.current.pausedAt = now;
      if (p && clock.current.pausedAt != null) {
        clock.current.start += now - clock.current.pausedAt;
        clock.current.pausedAt = null;
      }
      const tick = (clock.current.pausedAt ?? now) - clock.current.start;
      const { layers, unsupported } = resolveLayers(manifest, { ...s, effect: s.effect ? { ...s.effect, startedAt: s.effect.startedAt - clock.current.start } : null }, tick);

      ctx.imageSmoothingEnabled = false;
      ctx.clearRect(0, 0, canvas.width, canvas.height);
      for (const op of layers) {
        const img = images.current.get(op.file);
        if (!img) continue;
        ctx.drawImage(img, op.sx, op.sy, op.w, op.h,
          (CANVAS.anchorX + op.dx) * scale, (CANVAS.anchorY + op.dy) * scale, op.w * scale, op.h * scale);
      }

      const key = unsupported.join(',');
      if (key !== lastUnsupported.current) {
        lastUnsupported.current = key;
        report?.(unsupported);
      }
      if (s.effect && !layers.some((op) => op.file.startsWith('effect/'))) end?.();
      frame = requestAnimationFrame(draw);
    };
    frame = requestAnimationFrame(draw);
    return () => cancelAnimationFrame(frame);
  }, [manifest, scale, ref]);

  return <Box sx={{ display: 'inline-block', lineHeight: 0, background: '#1f2833', borderRadius: 2 }}>
    {/* height auto keeps the aspect when a narrow viewport shrinks the width */}
    <canvas ref={ref} width={CANVAS.width * scale} height={CANVAS.height * scale}
            style={{ maxWidth: '100%', height: 'auto', display: 'block' }}/>
  </Box>;
};

export default PaperDollCanvas;
```

Note the effect timing: the page stores `effect.startedAt = performance.now()` when a talent is clicked; the draw loop converts it into the canvas clock by subtracting `clock.start`. `onEffectEnd` fires once the effect no longer resolves, and the page clears `state.effect` (so the "effect set but not drawn" check fires once, not forever: the page must null it out).

  }, [router.isReady, router.query]);

  // state -> URL, shallow so the page does not reload. These params are page-local by design.
  useEffect(() => {
    if (!hydrated.current) return;
    const query = encodeLoadout({ ...loadout, pose: poseChoice === 'attack' ? '0' : poseChoice });
    router.replace({ pathname: router.pathname, query }, undefined, { shallow: true, scroll: false });
  }, [loadout, poseChoice]);

  const baseClass = getBaseClass(loadout.className) ?? 'Beginner';
  const pose = poseChoice === 'attack' ? attackPoseForType(loadout.weapon?.Type, baseClass) : poseChoice;
  const dollState = { ...loadout, pose, baseClass, effect };

  const pickCharacter = (character) => {
    setCharacterName(character?.name ?? '');
    if (character) setLoadout(loadoutFromCharacter(character));
  };

  const cast = (talent) => {
    setPoseChoice('attack');
    const mapped = effectForTalent(talent.name);
    setEffect(mapped ? { ...mapped, startedAt: performance.now() } : null);
  };

  const download = () => {
    const url = canvasRef.current?.toDataURL('image/png');
    if (!url) return;
    const a = document.createElement('a');
    a.href = url;
    a.download = `${loadout.className}-canvas.png`;
    a.click();
  };

  return <>
    <NextSeo
      title="Character Canvas | Idleon Toolbox"
      description="Dress up a Legends of Idleon character with any hat, weapon, cape and costume and watch it animate the way the game draws it"
      canonical={PAGE_URL}
    />
    <Typography variant={'h4'} mb={2}>Character Canvas</Typography>
    <Stack direction={'row'} gap={3} flexWrap={'wrap'} alignItems={'flex-start'}>
      <Card sx={{ flex: '0 0 auto' }}>
        <CardContent>
          <Stack gap={2} alignItems={'center'}>
            <PaperDollCanvas manifest={manifest} state={dollState} playing={playing} canvasRef={canvasRef}
                             onEffectEnd={() => setEffect(null)} onUnsupported={setUnsupported}/>
            <PoseBar pose={poseChoice} playing={playing}
                     onPose={(id) => { setPoseChoice(id); setEffect(null); }}
                     onTogglePlay={() => setPlaying((p) => !p)} onDownload={download}/>
            <AttackList className={loadout.className} onCast={cast}/>
          </Stack>
        </CardContent>
      </Card>
      <Card sx={{ flex: '1 1 320px' }}>
        <CardContent>
          <Stack gap={2}>
            <SourcePicker characters={characters} className={loadout.className} characterName={characterName}
                          onPickCharacter={pickCharacter}
                          onPickClass={(className) => { setCharacterName(''); setLoadout((l) => ({ ...l, className })); }}/>
            <SlotGrid loadout={loadout} unsupported={unsupported} onSlotClick={setPickerSlot}/>
          </Stack>
        </CardContent>
      </Card>
    </Stack>
    <ItemPickerDialog open={!!pickerSlot} slot={pickerSlot} baseClass={baseClass} value={pickerSlot ? loadout[pickerSlot] : null}
                      onPick={(item) => setLoadout((l) => ({ ...l, [pickerSlot]: item }))}
                      onClose={() => setPickerSlot(null)}/>
  </>;
};

export default CharacterCanvas;
